# HisabDo Mobile App – User Feedback Report

## Objective

The purpose of this user research was to collect genuine feedback
from real users after introducing them to the HisabDo mobile application.

Five users were asked to explore the application and provide honest
feedback about usability, useful features, issues, and possible improvements.

## Overall Findings

### Positive Feedback

- Users generally found the application easy to use.
- Dashboard and Transactions were considered useful.
- Reports and Analytics were appreciated for business insights.
- The interface and navigation were generally considered clean and simple.

### Common Issues

- Some users experienced minor confusion with categories or information.
- First-time users may benefit from additional guidance.
- Some business information could be presented more clearly.

### Recommended Improvements

Based on the collected feedback, the following improvements are recommended:

1. Add PIN and biometric security options.
2. Strengthen privacy and trust-related features.
3. Add notifications and reminders.
4. Improve category descriptions and organization.
5. Add a short onboarding tutorial for new users.
6. Improve charts and visual presentation of reports.
7. Use clearer labels throughout the application.
8. Consider Urdu/local-language support.

## Conclusion

The user feedback indicates that HisabDo has a generally simple
and understandable user experience. Users particularly appreciated
the Dashboard, Transactions, Reports, and Analytics features.

The main improvement opportunities are security, onboarding,
notifications, clearer information presentation, category usability,
and local-language support.
